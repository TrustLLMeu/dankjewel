BASE CLASSES (src/base.py)

✅ DimensionScore
   - Stores single dimension evaluation result
   - Fields: name, value (0-1), raw_value, metadata
   - Methods: to_dict(), to_json()

   - Stores evaluation result from one prong
   - Fields: prong_name, dimensions[], processing_time, error
   - Methods: to_dict(), to_json()

   - Base class for all evaluation dimensions
   - Method: evaluate(text) -> DimensionScore

✅ Evaluator (Abstract)
   - Base class for prong evaluators
   - Manages multiple dimensions
   - Method: evaluate(text) -> ProngResult

PRONG 2: RULE-BASED (FULLY IMPLEMENTED)
---------------------------------------
✅ FluidityDimension
   - Uses textstat.flesch_reading_ease()
   - Normalizes 0-100 to 0-1 range
   - Higher = more fluent

✅ PolitenessDetection
   - Lexical cue scoring
   - Baseline: 0.5
   - +0.1 per politeness cue (please, thank, etc.)
   - -0.1 per rudeness cue (pronto, hurry, etc.)

✅ EmotionalIntensity
   - VADER sentiment analysis
   - Punctuation counting (!, ?)
   - Combined scoring with bounds [0, 1]

✅ FormalityDimension
   - Formal markers: dear, would, may, respectfully, etc.
   - Informal markers: hey, gonna, wanna, dude, lol, etc.
   - Score: 0.5 baseline ± marker contributions

✅ HedgingDetection
   - Modal verbs: may, might, could, can, should, would
   - Uncertainty cues: perhaps, maybe, possibly, seems, appears
   - Higher score = more hedging/uncertainty

AGGREGATION (src/aggregation/)
------------------------------
✅ ScoreNormalizer
   - Min-max normalization per dimension
   - Handles edge cases (min == max)

✅ ScoreAggregator
   - Weighted average: M = w₁S₁ + w₂S₂ + w₃S₃ + w₄S₄
   - Default weights: 0.25 per prong (equal)
   - User-configurable weights
   - Computes:
     * Total score
     * Per-prong scores (average of dimensions)
     * Per-dimension scores
     * Processing metadata

MAIN PIPELINE (src/pipeline.py)
-------------------------------
✅ EvaluationPipeline
   - Initialize with enabled prongs [1,2,3,4]
   - Methods:
     * evaluate(text) -> dict (full results)
     * evaluate_to_json(text) -> str (JSON output)
   - Handles errors gracefully
   - Aggregates all prong results
