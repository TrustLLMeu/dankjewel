CONFIGURATION & USAGE
================================================================================
Basic Usage Example:
  from src.pipeline import EvaluationPipeline
  # Initialize with specific prongs
  pipeline = EvaluationPipeline(enable_prongs=[2, 3])
  # Evaluate text
  text = "Hello world!"
  result = pipeline.evaluate(text)
  # Get JSON output
  json_str = pipeline.evaluate_to_json(text)
Custom Configuration:
  from src.aggregation.aggregator import ScoreAggregator
  # Custom weights (must sum to 1.0)
  weights = {
      'LLM-as-Judge (Prong 1)': 0.4,
      'Rule-Based (Prong 2)': 0.3,
      'Extraction-Based (Prong 3)': 0.2,
      'Intrinsic (Prong 4)': 0.1
  }
  aggregator = ScoreAggregator(weights=weights)
Single Dimension Usage:
  from src.dimensions.prong2_dimensions import FluidityDimension
  fluency = FluidityDimension()
  score = fluency.evaluate("Simple text.")
  print(f"Fluency: {score.value} (raw: {score.raw_value})")
Full Example Available: python3 main.py

KNOWN LIMITATIONS & FUTURE WORK
================================================================================
Current Limitations:
  • Prongs 1, 3, 4 are skeletons (not functional yet)
  • Rule-based lexicons are English-centric
  • No multilingual support yet
  • No visualization/dashboard
  • Scores are relative (0-1 normalized per batch)
  • No ground truth available for arbitrary text
Design Decisions:
  • Local execution only (no API yet)
  • JSON output format (visualization later)
  • Modular design allows graceful degradation
  • Min-max normalization per dimension
  • Equal default weights for all prongs
Future Enhancements:
