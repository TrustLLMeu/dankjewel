DIMENSIONS IMPLEMENTED
================================================================================
1. RELEVANCE (Sentence-BERT embeddings)
   - Input: prompt (optional) + response
   - Fallback: First sentence as pseudo-prompt if no prompt
   - Output: [0, 1] cosine similarity score
   - Latency: ~10-20ms
2. SEMANTIC COHERENCE (Sentence-BERT embeddings)
   - Input: response (multi-sentence)
   - Process: Adjacency sentence similarities
   - Output: [0, 1] coherence score
   - Latency: ~20-100ms
3. RELIABILITY (Embedding variance)
   - Input: one or more responses
   - Process: Single-response internal consistency OR multi-response similarity variance
   - Output: [0, 1] reliability score
   - Latency: ~20-100ms
4. TOXICITY (unitary/toxic-bert)
   - Input: response text
   - Process: DistilBERT classification
   - Output: [0, 1] toxicity probability
   - Latency: ~20-80ms
Total Latency: 150-400ms per text (depends on text length, no GPU)

API CONTRACT
================================================================================
Prong1LLMAsJudge.evaluate(text, prompt=None, responses=None) -> ProngResult
Input:
  - text (str, required): Generated text to evaluate
  - prompt (str, optional): Original prompt for relevance scoring
  - responses (List[str], optional): Multiple responses for reliability
Output (ProngResult):
  - prong_name: "LLM-as-Judge (Prong 1)"
  - dimensions: [
      {name: "Relevance", value: float, raw_value: float, metadata: dict},
      {name: "Semantic Coherence", value: float, ...},
      {name: "Reliability", value: float, ...},
      {name: "Toxicity", value: float, ...}
    ]
  - processing_time: float (seconds)
  - error: null or error message
